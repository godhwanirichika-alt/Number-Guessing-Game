Number Guessing Game

About the Project

This is a console-based Number Guessing Game developed using C programming. The computer generates a random number, and the player has to guess it within 10 attempts.

Features

- Random number generation
- Maximum 10 attempts
- Hints to guess a higher or lower number
- Input validation for invalid numbers
- Win or lose message
- Displays the number of attempts used

Technologies Used

- C Programming
- GCC Compiler
- Visual Studio Code

How to Play

1. Run the program.
2. Enter a positive whole number.
3. Follow the hints to guess the correct number.
4. Guess the number within 10 attempts to win.
